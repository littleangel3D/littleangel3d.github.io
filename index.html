Chuyển sang bản lưu dữ liệu trên máy chủ

Bản Cloud có database, đồng bộ giữa thiết bị và xác nhận lưu. Đăng nhập bằng tài khoản quản lý trước khi chỉnh sửa.

Trình duyệt này còn dữ liệu từ bản GitHub cũ. Dữ liệu vẫn được giữ nguyên. Hãy tải JSON để chuyển sang bản Cloud.
  1. Tải bản sao lưu JSON bên dưới.
  2. Mở bản Cloud và đăng nhập.
  3. Vào Cài đặt → Nhập JSON để đưa dữ liệu vào database.
Mở bản Cloud

GitHub Pages là nơi mở ứng dụng; dữ liệu thật được quản lý tại bản Cloud. Bản này không tiếp tục nhận chỉnh sửa chỉ lưu cục bộ.
